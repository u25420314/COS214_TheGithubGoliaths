Detailed Description

One running copy of a workflow, created from a WorkflowDefinition.

An instance holds its own deep-cloned tree of WorkNodes (Prototype pattern), so changing one instance never affects another. It also stores the instance's id, its status and the WorkflowData supplied when it was started.

The instance owns its tree: the destructor deletes the root. It cannot be copied.
