Defines the WorkNode abstract base class for the Composite pattern.

This file is part of the Workflow Model subsystem (Composite pattern). WorkNode serves as the Component interface in the Composite hierarchy. It defines the common operations for both individual Tasks (Leaf) and Stages (Composite).
