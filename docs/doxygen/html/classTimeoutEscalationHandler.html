Detailed Description

Escalates approval requests that exceed a waiting time limit.

this class is concretehandler in the chain or resposnibility

it exmaines the number of days an approved request has been waiting and compares it against a configured time limit

if the request time is exceeded the limit the requetss decision will be changed to escalated
