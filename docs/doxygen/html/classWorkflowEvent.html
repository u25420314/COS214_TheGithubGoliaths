Detailed Description

An event in a workflow, published by engine to observers.

Author
Simon Vogel

This class is meant to represent an event within the workflow, such as assigning a task or performing an action. It is used by WorkflowObserver to update WorkflowSubject as well as to update the WorkflowEngine.
