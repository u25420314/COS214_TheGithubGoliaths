Detailed Description

Defines the TividyGUI class, which provides the FTXUI-based frontend for the Tividy Workflow System.

This file contains the declaration of the TividyGUI class. It acts as the Presentation layer, interacting with the backend through the TividySystem Facade. It uses the FTXUI library to render a terminal-based user interface, manage state for forms/tabs, and display audit logs.
