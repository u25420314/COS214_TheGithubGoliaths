Detailed Description

The Graphical User Interface class for the Tividy system.

Author
Simon Vogel Encapsulates entire FTXUI layout, event handling, and state management. It provides four main tabs: Dashboard, Instances, Tasks, and Audit Log. It also includes automated testing scripts (University/Insurance demos) that exercise the backend logic.
