Detailed Description

Represents a request for approval of a task.

This class stores information about a task to be processed by the chain of resposibility

each approval contains a pointer to the task, its current approval decision and the number of days its been waiting

ApprovalHandlers use this information to determine whetehr a rewquest shoulf be approved, escalted, or passed to the next handler in the chain
